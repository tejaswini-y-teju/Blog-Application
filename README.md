# BlogSpace 📝

BlogSpace is a simple and responsive blog application that allows users to create an account, log in, create blogs, and share their ideas with others.

## Features

- User Registration
- User Login
- Dashboard
- Create New Blog
- Blog Categories
- Publish Blog
- Views and Likes
- Responsive Design

## Technologies Used

- HTML
- CSS
- JavaScript
- Git
- GitHub

## Live Demo

https://tejaswini-y-teju.github.io/Blog-Application/

## Project Structure

- `index.html` – Home page
- `login.html` – Login page
- `register.html` – Registration page
- `dashboard.html` – User dashboard
- `create-blog.html` – Create and publish blogs
- `style.css` – Styling
- `script.js` – JavaScript functionality
